# \# Investment Portfolio Manager

# 

# A relational database project developed using SQL and SQLite for managing investment portfolios, assets, holdings, and transactions.

# 

# \## Overview

# 

# The Investment Portfolio Manager is designed to organize and manage investment data through a structured relational database. The project demonstrates database design, SQL querying, data integrity, and portfolio-related data management.

# 

# \## Features

# 

# \- Manage users and investment portfolios

# \- Store and organize financial asset information

# \- Track portfolio holdings

# \- Record investment transactions

# \- Analyze portfolio and transaction data

# \- Maintain relationships between users, portfolios, assets, holdings, and transactions

# 

# \## Technologies

# 

# \- SQL

# \- SQLite

# \- Relational Database Design

# 

# \## Project Structure

# 

# \- `schema.sql` – Defines the database schema, tables, relationships, constraints, indexes, views, and triggers

# \- `queries.sql` – Contains SQL queries for interacting with and analyzing portfolio data

# \- `DESIGN.md` – Documents the database design and implementation decisions

# 

# \## Skills Demonstrated

# 

# \- Relational database design

# \- Primary and foreign key relationships

# \- SQL queries

# \- Views and triggers

# \- Data integrity and constraints

# \- Database indexing

#
